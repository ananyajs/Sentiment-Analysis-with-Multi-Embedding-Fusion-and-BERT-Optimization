# Sentiment Analysis with Multi-Embedding Fusion and BERT Optimization

## Overview
This project focuses on sentiment analysis using a multi-embedding fusion approach combined with BERT optimization. It explores various word embedding techniques and integrates them into a unified model to improve sentiment classification performance. The project also fine-tunes BERT to achieve better accuracy in sentiment analysis tasks.

## Features
- **Multi-Embedding Fusion**: Utilizes multiple embedding techniques such as TF-IDF, Word2Vec, GloVe, and FastText.
- **BERT Optimization**: Fine-tunes BERT to enhance sentiment classification.
- **Comparative Analysis**: Evaluates the performance of traditional and modern deep learning approaches.
- **Dataset Preprocessing**: Includes text cleaning, tokenization, and feature extraction.
- **Model Training & Evaluation**: Implements various models and compares their effectiveness.

## Dataset
The resturant review dataset used for this project is has been preprocessed and stored in `modified_dataset.csv`. It contains labeled text data for sentiment analysis.

## Results
- The multi-embedding fusion approach improves sentiment analysis accuracy.
- Fine-tuning BERT yields superior performance compared to traditional embedding methods.
